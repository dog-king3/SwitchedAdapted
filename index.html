Switch on the Joy

Making toys more accessible for every child.

We adapt toys so children with disabilities can easily interact with them using an accessible external switch.

Learn more See Last Year's Event

We create accessible solutions that remove barriers

Many children with disabilities face barriers when they try to interact with everyday toys. Small buttons, fine-motor demands, and complicated controls can make play harder than it should be.

Switch on the Joy modifies toys so they can be activated with a large external switch. The result is more independent play and joy.
